# Подключение сайта к МИС SQNS / 1Дента

Что это даёт: слоты в форме записи на сайте показывают реальную занятость из
программы на ресепшене; заявки с сайта создают записи в МИС; отмена в админке
сайта отменяет запись и в программе.

## 1. Обнови код

В архиве лежит актуальная версия проекта. Главное для интеграции:

- `server/sqns.js` — адаптер CRM Exchange API
- `server/index.js` — `/api/slots` и `/api/bookings` ходят в SQNS
- `server/db.js` — колонки `sqns_employee_id`, `sqns_service_id`, `sqns_visit_id`
- `server/map-sqns.js` — скрипт привязки врачей сайта к сотрудникам МИС
- `src/pages/admin/AdminPage.tsx` — поля «ID в SQNS» у врача и услуг

Если у тебя своя версия — можешь взять эти файлы поверх, либо
`git pull` из `https://github.com/kudinov13/CaratDental.git` (ветка `main`).

## 2. Проверь .env в корне проекта

Готовый `.env` со всеми данными уже лежит в архиве — ничего
создавать не нужно. Просто убедись, что файл на месте
(он скрытый, в проводнике может не отображаться без включённых
«скрытых элементов»).

Внутри: доступ к SQNS (`SQNS_ENABLED=1`, email и пароль МИС),
порт `PORT=3001`, вход в админку (`ADMIN_LOGIN` / `ADMIN_PASSWORD`)
и `KARAT_SECRET` для сессий админки.

Важно: `SQNS_PASSWORD` обязательно в двойных кавычках — внутри есть `#`,
без кавычек dotenv обрезает пароль и вход падает с 423.

`.env` никогда не коммитить в git — он в .gitignore. Файл с паролями
передавать только напрямую, не через общие чаты.

## 3. Привяжи врачей к сотрудникам SQNS

В SQNS у каждого сотрудника есть employeeId. Маппинг по умолчанию
(по нашей клинике):

| Сайт (doctorId) | SQNS employeeId | Кто |
|---|---|---|
| suhanova | 1 | Суханова Марина Николаевна |
| sukhorukova | 6 | Сухорукова Регина Рафисовна |
| irisbekov | 12 | Ырысбеков Эгем Ныязалиевич |
| rabadanov | 16 | Рабаданов Багомед Рабаданович |
| amonatzoda | 17 | Амонатзода Салмон Рахимович |

Применить одной командой из корня проекта:

```
node server/map-sqns.js
```

Или вручную через админку `/admin` → «Врачи и цены» → Изменить →
поле «ID врача в SQNS».

Если врачей в SQNS больше — их id можно посмотреть в МИС (Сотрудники)
или вызовом `GET /api/v2/employee` с токеном (см. server/sqns.js).

## 4. Запуск

```
npm install
npm run dev:all
```

Сайт: http://localhost:5173, API: http://localhost:3001.

При старте в консоли `[api]` должно быть `injected env (8)` —
значит переменные подхватились.

## 5. Проверка

1. Открой сайт → «Записаться» → выбери врача с привязкой (напр. Суханова) →
   дату. Свободные слоты должны совпадать с расписанием в программе.
2. Создай тестовую запись — она появится в МИС как визит, клиент
   заведётся с телефоном.
3. В нашей админке `/admin` → «Записи» → поставь «Отменена» —
   в МИС визит уйдёт в статус cancel, слот освободится и на сайте.

## Если SQNS недоступен

Сайт автоматически откатится на локальную БД (слоты по расписанию
из админки, занятость по нашим записям). В консоли будет
`[SQNS] ... fallback to local`. Поставь `SQNS_ENABLED=0`, чтобы
вообще не ходить в МИС.
