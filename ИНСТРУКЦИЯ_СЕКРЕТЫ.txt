ИНСТРУКЦИЯ: подключение SQNS к проекту, скачанному с гита
==========================================================

Что в архиве:
  .env            — секреты (доступ к МИС SQNS, админка, KARAT_SECRET)
  map-sqns.js     — скрипт привязки врачей сайта к сотрудникам МИС
  SQNS_SETUP.md   — подробное описание (на всякий случай)

Шаг 1. Распаковать в корень проекта
-----------------------------------
Положи файлы так:

  <папка проекта>\.env
  <папка проекта>\server\map-sqns.js
  <папка проекта>\SQNS_SETUP.md

ВАЖНО: .env должен лежать именно в КОРНЕ проекта (рядом с
package.json), а НЕ в server\ или src\.
Файл скрытый — в проводнике включи "Скрытые элементы", чтобы его видеть.

Шаг 2. Привязать врачей к SQNS
-------------------------------
Из корня проекта выполни:

  node server/map-sqns.js

В консоли появится список врачей с присвоенными SQNS ID
(Суханова → 1, Сухорукова → 6, Ырысбеков → 12, Рабаданов → 16,
Амонатзода → 17). Если какого-то врача нет в твоей БД — добавь
его ID через админку: /admin → "Врачи и цены" → Изменить →
поле "ID врача в SQNS".

Шаг 3. Запустить
----------------

  npm install
  npm run dev:all

Проверка что всё подхватилось:
- при старте в консоли [api] должно быть "injected env (8)"
- сайт: http://localhost:5173, API: http://localhost:3001

Шаг 4. Проверить связь с программой
-----------------------------------
1. Сайт → "Записаться" → выбери врача с привязкой (например Суханова)
   → дата. Свободные слоты должны совпадать с расписанием в МИС.
2. Создай тестовую запись — она появится в программе на ресепшене
   как визит, клиент заведётся с телефоном.
3. /admin → "Записи" → статус "Отменена" — визит в МИС отменится,
   слот освободится и на сайте.

Если не работает
----------------
- "Invalid login or password" в консоли → проверь, что
  SQNS_PASSWORD в .env стоит в двойных кавычках (там есть символ #,
  без кавычек dotenv обрезает пароль).
- Проверь, не занят ли порт 3001 старым процессом:
  netstat -ano | findstr :3001 → убить процесс по PID → перезапустить.
- SQNS_ENABLED=0 в .env полностью выключает интеграцию (слоты будут
  из локального расписания админки).

Осторожно:
  .env НИКОГДА не коммитить в git (он уже в .gitignore — просто не
  обходи это). Архив хранить у себя, в общие чаты не скидывать.
